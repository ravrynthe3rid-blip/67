# Wisp (Fabric, Minecraft 26.2, Java 25)
Items: Division (clock, toggles slow time), Dilation (fishing rod, swap places),
Fractured (netherite pickaxe, Haste V + Speed II, mines bedrock + end portal frames),
Book of Knowledge (blue book, click a mob to summon it for 10-400 XP).

Build: copy `src/` into a project from https://fabricmc.net/develop/template/ (26.2),
or add a Gradle 9.3+ wrapper here, then run `./gradlew build`. Jar: build/libs/.
